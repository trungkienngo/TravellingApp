TravellingApp demo - không sử dụng Firebase.
1. npm install
2. npx expo start --web --clear
3. Vào Sign up, tạo tài khoản thử (mật khẩu >= 6 ký tự), sau đó Sign in.
4. Dữ liệu phòng mẫu: data/places.js; lưu người dùng, favorites, booking, reviews bằng AsyncStorage.
LƯU Ý: Dữ liệu demo chỉ trên thiết bị. Mật khẩu lưu cục bộ dạng rõ, không dùng tài khoản thật. Các nút Facebook/Apple/Google chỉ mở website. Ảnh phòng từ Unsplash cần internet.
